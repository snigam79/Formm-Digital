How to read this

  • Priority: HIGH can interrupt · MED normal · LOW silent/batched
  • trigger = condition to detect in code · frequency = hard cap (dedupe/cooldown) · deep_link = where tapping lands
  • Global rules (all notifications): respect OS permission; quiet hours 21:00–08:00 (only HIGH overrides); max 2 push/day total; if app is foregrounded, show in-app instead of push; every item toggleable in Settings → Notifications.
